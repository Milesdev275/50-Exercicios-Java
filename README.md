# 50 Exercícios Java 🚀

Coleção de 50 exercícios práticos em Java, organizados por nível de dificuldade e conceito: variáveis e entrada de dados, estruturas condicionais simples (`if`), condicionais compostas (`if/else`), condicionais encadeadas (`if/else if`), operador ternário e `switch`.

Repositório: [Milesdev275/50-Exercicios-Java](https://github.com/Milesdev275/50-Exercicios-Java) · Pasta dos exercícios: [`CinquentaExercicios/`](https://github.com/Milesdev275/50-Exercicios-Java/tree/main/CinquentaExercicios)

> Clique no número ou no nome de qualquer exercício abaixo para abrir o código-fonte direto no GitHub.

## 🛠️ Como executar

```bash
git clone https://github.com/Milesdev275/50-Exercicios-Java.git
cd 50-Exercicios-Java/CinquentaExercicios
javac Exercicio1.java
java Exercicio1
```

Basta trocar `Exercicio1` pelo número do exercício que deseja rodar.
